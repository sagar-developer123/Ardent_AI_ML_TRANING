## 🗂️ Projects

### 📊 Project 1 — EDA Dashboard (Titanic Dataset)
> *Exploratory Data Analysis | Visual Insights*

A beginner-friendly EDA project built in Google Colab using a real-world dataset.

**What I did:**
- Loaded and explored columns using **Pandas**
- Handled missing values using mean and mode imputation
- Created visualizations: survival count, gender vs survival, age distribution
- Summarized key insights in a presentation-ready format

**Tech Stack:** `Python` `Pandas` `Matplotlib` `Google Colab`

---

### 🏠 Project 2 — House Price Prediction
> *Linear Regression | Model Evaluation (RMSE, R²)*

My first supervised ML model — trained to predict house prices on unseen test data.

**What I did:**
- Performed train-test split to avoid data leakage
- Trained a **LinearRegression** model using **scikit-learn**
- Evaluated performance using **RMSE** and **R² score**
- Visualized Actual vs Predicted values and residual errors

**Tech Stack:** `Python` `scikit-learn` `Pandas` `Matplotlib` `Google Colab`
